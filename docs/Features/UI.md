# In-Game UI & Text

- Text rendering with SDF fonts (via stb_truetype), crisp at any size
- Screen-space UI elements: text, image, panel and button
- Anchored layout so UI adapts to different window sizes and aspect ratios
- Authored as components in the editor and controllable from scripts
- Bundled fonts must meet the license rules in AGENTS.md - whether SIL OFL fonts are allowed is an [open decision](../Milestones.md#open-decisions)
